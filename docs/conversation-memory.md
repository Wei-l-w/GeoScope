# 地图分析的对话记忆

聊天记录、模型本轮能看到的上下文、新闻知识库是三个独立部分。本功能管理前两者，RAG 新闻索引仍按原方式检索。

## 使用

可以先问“曼德海峡周边150公里有哪些事件”，再问“半径改成200公里”；或者先指定 MMSI 和最近30天，再问“这艘船改查最近7天”。模型会收到当前条件和近期工具证据，条件更改后仍需重新查询。

侧栏“本会话记忆”可以查看船号、地点、坐标、时间窗、半径、筛选条件和早期摘要。重新打开原会话会恢复记忆；新建会话从空白开始。同名会话以独立 ID 保存和选择。

“清空分析记忆”保留聊天记录和已有地图，但设置持久化边界，后续不再把清空前的消息用于摘要、状态或模型上下文。清空前正在执行的请求若稍后返回，其孤立回答可以保留查看，但不会恢复已清空的分析条件。

## 保存和提取

- `chat_messages` 保存完整问答、结构化工具参数/返回、成功或阻断状态、错误和地图路径。
- `chat_memory` 保存每个会话的记忆 JSON 和清空边界；旧数据库仅增加列和表，原问答不改写。记忆是派生数据：提取规则升级时版本号随之变更，旧快照按原始问答整体重建（坐标这类可能记错的字段不会靠增量沿用）。
- 近期窗口默认 5 轮，更早的已完成问答生成有界摘录摘要。失败轮次明确标为失败；未完成的问题不补造答案。
- 状态从明确用户表达及成功工具中提取，附来源。更换地点会清除旧坐标，更换船号不会携带旧航迹；时间窗、半径和筛选可更改或取消。
- 支持常见 MMSI、正整数天数、明确日期范围/月份、公里半径、风险等级、国家、船型等写法。未知筛选保留原文，复杂或含糊条件仍需要模型结合当前问题理解或澄清。
- 成功执行的工具也可能使用错误参数，因此冲突工具不能覆盖明确用户条件或恢复已取消字段。旧会话没有保存过的工具证据不会被补造。
- 所有摘要和条件整理本地执行，不新增摘要模型调用。摘要是摘录式压缩，并非无限保存全部语义；完整原文始终另外保存。

历史资料作为单独的数据消息进入模型上下文，当前问题优先；历史中的提示、旧指令、旧统计数字不能代替当前要求或新的查询结果。

## 配置

| 环境变量 | 默认值 | 用途 |
| --- | --- | --- |
| `AGENT_HISTORY_TURNS` | 5 | 近期对话轮数，至少保留一轮 |
| `AGENT_HISTORY_QUESTION_CHARS` | 2000 | 每条历史问题的字符上限 |
| `AGENT_HISTORY_ANSWER_CHARS` | 800 | 每条历史回答的字符上限 |
| `AGENT_HISTORY_TOOL_CHARS` | 1600 | 每条历史助手消息附带工具证据的字符上限 |
| `AGENT_MEMORY_SUMMARY_CHARS` | 3000 | 早期摘录摘要的字符上限，0 可关闭摘录 |
| `SESSIONS_DB_PATH` | `data/sessions.duckdb` | 会话与记忆数据库 |

验证使用临时数据库和模型替身，覆盖长期对话、重启恢复、同名会话、切换隔离、条件修改/取消、工具失败、并发清空和迟到回复。它验证数据保留与提示注入链路，不代表所有自然语言追问都经过在线模型验证。
